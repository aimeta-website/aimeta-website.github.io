# aimeta.website

The AIMeta brand portal — **AI for everyday life.**

Pure static HTML/CSS/JS, deployed straight to GitHub Pages. No build step, no Jekyll.

## Structure

```
index.html      Homepage — hero, Press/Host/Fun cards, live projects, flywheel, about, updates
press.html      AIMeta Press — local intelligence network
host.html       AIMeta Host — digital services & infrastructure
fun.html        AIMeta Fun — games & experiments
about.html      Brand story & company
updates.html    Changelog
404.html        Not found (on-brand)
css/style.css   Shared voxel design system
js/main.js      Nav toggle, reveal-on-scroll, footer year
favicon.svg     Pixel grass-block cube
sitemap.xml / robots.txt
CNAME           Custom domain (do not remove)
```

## Design

Minecraft/Roblox-inspired voxel style: Press Start 2P pixel accents + Inter body,
chunky offset shadows, floating voxel cubes, grass-block dividers. Bright saturated
palette, responsive with mobile nav.

## Deploy

Push to `main` — GitHub Pages serves it as-is.
